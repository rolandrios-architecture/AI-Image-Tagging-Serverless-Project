3) Error: Reference to undeclared input variable
Message: Error: Reference to undeclared input variable
Location: main.tf line 6 (bucket = var.aws.s3_bucket_name)
Cause: Code referenced `var.aws.s3_bucket_name` using dotted namespace syntax; Terraform treats `var` as the variable namespace and does not support nested dotted variable names unless a variable named `aws` is declared. The declared variable is `aws_s3_bucket_name`.
Solution: Update references to use `var.aws_s3_bucket_name` (underscore-separated), matching the declared variable name in `variables.tf`.
Status: Patched `main.tf` to `var.aws_s3_bucket_name` on 2026-04-14.

4) Error: Invalid function argument - jsondecode called with object
Message: Invalid value for "str" parameter: string required, but have object.
Location: main.tf lines ~33-48 (aws_s3_bucket_policy resource)
Cause: The code called `jsondecode({ ... })` passing an HCL object directly. `jsondecode` expects a JSON string, not an object.
Solution: Use `jsonencode({ ... })` to convert the HCL object to a JSON string, or supply a JSON string directly (heredoc). Patched `main.tf` to use `jsonencode(...)` on 2026-04-14.
Status: Patched on 2026-04-14. Please run `terraform validate`.

Recommended verification:

