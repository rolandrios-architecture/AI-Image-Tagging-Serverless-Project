4) Error: Invalid function argument - jsondecode called with object
Message: Invalid value for "str" parameter: string required, but have object.

Solution: Use `jsonencode({ ... })` to convert the HCL object to a JSON string, or supply a JSON string directly (heredoc). Patched `main.tf` to use `jsonencode(...)` on 2026-04-14.
